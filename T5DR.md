# T5;DR — TranchNOSE

Normal computers mostly work by **passing messages**.

TranchNOSE asks whether some computation can instead happen because many nodes participate in the **same shared physical field**.

Think of two ways friends can make a song:

- **Passing notes:** one person sends information to another.
- **Singing together:** everyone contributes to one shared pattern that no single person is the whole of.

TranchNOSE gives the machine three jobs:

1. **Electronics remember.**
2. **A small coordination network keeps everything synchronized and healthy.**
3. **The optical field carries the fast shared pattern.**

The coordination network is intentionally too limited to secretly carry the whole pattern.

Then we damage the optical pattern — remove nodes, scramble phases, remove channels, add noise — and ask:

> **Can the system reconstruct the right shared pattern anyway?**

If it can, while no individual node or hidden control channel contains enough information to rebuild the result directly, then the relationships among the nodes are doing real computational work.

That is the core hypothesis:

> **Topology is state.**

Or, even shorter:

> **Normal computers pass notes. TranchNOSE asks what happens when the nodes sing together.**
